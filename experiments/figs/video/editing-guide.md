## 重生成管线（素材变了随时重跑）

```bash
bash voice/synth-lines.sh    # 1) mmx TTS 逐句合成（17 句，含 --subtitles）
bash voice/build-voice.sh    # 2) 按对轨表铺 130.52s 配音轨 + voiceover.srt
bash voice/synth-bgm.sh      # 3) ffmpeg 程序化 BGM
cd post && bash build-cards.sh && cd ..   # 4) SVG → 卡片 PNG（rsvg-convert）
bash post/assemble.sh        # 5) 总装 → poolhall-final.mp4
```

## 配音规格（已落实）

- mmx `speech-2.8-hd`，voice `Chinese (Mandarin)_Gentleman`，pitch −2（低沉纪录片腔）

## 配乐方案（ffmpeg 合成，A 小调暗色纪录片底）

- 低频 drone（55Hz + 82.4Hz）+ 粉红噪声低通 = 全片底噪
- 稀疏 felt piano 单音；**读人段（80.4–109.2s）音符表留空 = 音乐全撤只留低频底噪**
- 胜利段转 A 大调色彩；片尾 3s 淡出
